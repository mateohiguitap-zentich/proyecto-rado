MANUAL DE USUARIO: MÓDULOS PRINCIPALES

SISTEMA FACTURACIÓN RADO

Este manual de usuario servirá de guía detallada para que el personal administrativo, de recepción y técnicos pueda utilizar de manera óptima nuestra plataforma web RADO. El documento describe las funcionalidades principales, los flujos de trabajo paso a paso y los diferentes módulos que componen el sistema, garantizando un registro eficiente de pacientes, la correcta generación de órdenes virtuales y el procesamiento de la facturación electrónica, además de generar reportes y gestionar usuarios.

Instrucciones de Ingreso al Sistema

Para iniciar el uso de la plataforma RADO, el usuario debe seguir estos pasos:

  1. Abrir un navegador web (se recomienda Google Chrome o Mozilla Firefox) e ingresar a la URL del sistema.
  2. En la pantalla de inicio de sesión, el usuario deberá digitar su Nombre de Usuario y su Clave Única.
  3. Dependiendo del rol asignado (Administrador, Recepcionista o Técnico), el sistema habilitará automáticamente los módulos correspondientes a sus funciones.

1. Módulo Panel de Control

En este módulo se encontrará un resumen del día dependiendo de la sede en donde estemos ubicados. Sirve como pantalla principal para visualizar métricas rápidas de la operación diaria, todo puede ser adaptable según lo desee el cliente.

2. Módulo Registro de Paciente

En este módulo se empieza a dar funcionamiento a la plataforma. Primeramente, iniciamos digitando el número de documento del paciente.

  • Si el documento digitado ya existe, el sistema automáticamente cargará la información asociada a ese número de documento ingresado.
  • De no estar registrado el número de documento, el usuario podrá pasar por cada uno de los datos que debe llenar usando el mouse o la tecla TAB. Es obligatorio llenar cada uno de los datos; de hacer falta alguno, el sistema mostrará un mensaje notificando qué datos hacen falta. En caso tal de que el paciente no desee registrar algún dato, el usuario pondrá NA.

Flujo de guardado: Una vez finalizada la captación de datos, el usuario deberá dar clic en el botón "FINALIZAR REGISTRO Y GENERAR ORDEN VIRTUAL" para que el sistema guarde los datos del paciente y el usuario contiene con la ORDEN VIRTUAL

3. Módulo Orden Virtual

El sistema cargará automáticamente la información necesaria del paciente en la sección “Datos del Paciente”.

El usuario deberá llenar la sección de “Información del Servicio”, donde podrá agregar uno o más estudios a realizar, el odontólogo remitente y su correo electrónico (en caso tal de no tener, se pone NA). También podrá agregar observaciones en la sección de “Información del Servicio” en caso de ser necesario.

En "Detalles de entrega", se debe seleccionar el formato de entrega: FÍSICO, VIRTUAL o FÍSICO/VIRTUAL.

Flujo de guardado: Una vez finalizada la sección, el usuario debe dar clic en “Guardar Orden” para poder que el sistema genere una ventana emergente donde el usuario podrá guardar la orden en formato PDF y ser enviado a los técnicos. Esta acción además servirá como puente para la generación de la factura electrónica.

4. Módulo Factura Electrónica

El sistema cargará de forma automática la información de factura, información de contacto, información de la clínica (según la sede donde estemos facturando) e información de facturación.

El usuario deberá diligenciar el valor a pagar y el método de pago (EFECTIVO, CONSIGNACIÓN/TRANSFERENCIA, TARJETA DÉBITO O TARJETA CRÉDITO).

Flujo de facturación: Una vez diligenciado todo correctamente, el usuario debe dar clic en "Guardar" botón que se encuentran en la parte superior derecha de la pantalla.

5. Módulo Generación de Reportes

Se podrá evidenciar por el momento: CONSOLIDADO POR SEDE, FACTURACIÓN POR SEDE y AGENDAMIENTO DE CITAS. (En un futuro se puede agregar otro tipo de reporte según las necesidades del cliente).

  • Filtros: La fecha de inicio debe ser inferior o igual a la fecha final.
  • Previsualizar: Botón donde el usuario podrá obtener una vista previa del informe solicitado.
  • Exportar: En este botón el sistema genera y descarga un archivo en formato Excel, según el informe solicitado.

6. Módulo Gestión de Usuario

A este módulo solo podrá tener acceso el personal administrativo autorizado. Acá se podrá:

  • Agregar un nuevo usuario: Se debe ingresar el número de documento, clave única y rol asignado. Si el número digitado ya se encuentra en uso, el sistema no dejará guardar la información.
  • Editar usuario: El usuario debe ingresar el número del documento que desea editar, donde podrá cambiar la clave y asignar un nuevo rol. Si el número de documento ingresado no existe, no generará ninguna acción.
  • Eliminar usuario: El usuario podrá eliminar un perfil existente ingresando su número de documento. Tras validarlo, el sistema mostrará una ventana de confirmación antes de proceder a la eliminación.
